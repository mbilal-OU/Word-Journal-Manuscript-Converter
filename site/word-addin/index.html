Word Citation Navigator

Word Journal Manuscript Converter · Pre-Launch Beta 1

Navigate between in-text citations and references inside Microsoft Word without rewriting live EndNote, Zotero, or Mendeley citation fields.

Pre-launch: the add-in is currently distributed for testing by sideloading. Public launch is planned through Microsoft Marketplace.

What it does

  • scans bracketed numbered citations and the bibliography inside the open document
  • detects EndNote, Zotero, and Mendeley/CSL field signatures
  • jumps to the first citation occurrence or matching reference
  • changes only the Word selection during navigation
  • offers optional anonymous add-in usage analytics with no document text

Install for pre-launch testing

Download the add-in manifest:

Download manifest.xml

Then use one of Microsoft's supported testing/deployment paths:

  1. Individual testing: sideload the manifest in Word/Office using Microsoft's Office Add-ins testing instructions.
  2. Windows desktop testing: Microsoft documents a trusted network-share catalog method for task-pane add-ins.
  3. Institutional pilot: a Microsoft 365 administrator can deploy the custom manifest through the Integrated apps area to selected users.

Microsoft documentation:

  • Sideload Office Add-ins for testing
  • Windows network-share sideloading
  • Microsoft 365 admin-center deployment

Public launch

Microsoft Marketplace is the intended stable-release distribution method. Marketplace distribution gives users the normal Office installation experience and supports managed add-in updates after publication.

Privacy

The citation scan runs through Office.js against the open document. Word Journal Manuscript Converter does not transmit the document text through its analytics system. Optional analytics record product actions only.

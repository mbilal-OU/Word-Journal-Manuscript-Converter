Designed for active research manuscripts

Citation Navigator complements the desktop application. Use the desktop app for journal conversion, template adaptation, linked review copies, and full DOCX preservation checks. Use the Word add-in when you want fast navigation while the live manuscript is open.

Trace citations

Scan the open document, identify citation/reference relationships, and move directly between the two locations.

Keep references live

Navigation changes the Word selection only. It does not intentionally rewrite EndNote, Zotero, or Mendeley field payloads.

Check document state

Run a lightweight integrity inspection from the task pane before continuing manuscript work.

Install for testing

The add-in is currently distributed as an Early Access Office add-in. Microsoft supports sideloading for testing and centrally managed deployment for organizations. Public store distribution is planned through Microsoft Marketplace after launch validation.

Privacy and manuscript safety

Citation and reference scans operate against the open Word document through Office.js. Optional product analytics can record actions such as add-in opened, citation scan, integrity check, or navigation action. Manuscript text, filenames, citation text, reference text, and document metadata are excluded from analytics.

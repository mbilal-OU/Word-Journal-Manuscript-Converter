Built for research manuscripts

Citation integrity

Recognizes citation-manager field signatures and maps plain numbered or conservative author-year citations to bibliography entries.

Fail-closed retargeting

Formatting changes are applied only to a copy. If the preservation audit detects protected-content drift, the generated file is rejected.

Human-readable reports

Generate a local HTML report with document inventory, citation resolution, journal checks, profile provenance, and machine-readable audit data.

Bundled journal profiles

Profiles record the official source and the date the guidance was checked. They evaluate only requirements supported by the current engine.

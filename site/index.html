Use the journal's own Word template

When a publisher supplies a .docx or .dotx template, Template Mode keeps the manuscript as the scientific-content source of truth and transfers only a conservative formatting subset into a new copy.

Transferred

Page size, orientation, margins, columns, line numbering, and selected standard Word styles.

Never imported

Template body text, placeholders, headers, footers, macros, figures, citations, or unrelated package relationships.

Verified after conversion

The output is kept only if the preservation gate confirms protected manuscript content survived safely.

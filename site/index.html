Word Journal Manuscript Converter is an integrity-first toolkit for existing Word manuscripts. It maps citations to references, audits sensitive DOCX structures, applies controlled journal formatting, and verifies that scientific content survived unchanged.

Not another Word formatter

The core design treats a manuscript as a structured scientific document, not a pile of paragraphs. Unsupported Word features are preserved by default, and every automated change must survive a post-transform integrity gate.

Citation integrity

Recognizes live citation-manager field signatures and maps plain numbered or author-year citations to bibliography entries.

Safe retargeting

Applies only profile rules that can be changed without rewriting scientific prose, such as margins, spacing, line numbering, and body styles.

Auditable output

Compares text, numeric tokens, fields, media hashes, custom XML, tracked changes, notes, equations, tables, bookmarks, and hyperlinks.

Three access paths

Desktop app

The main privacy-preserving interface. Choose a local DOCX, inspect it, run readiness checks, retarget a copy, and review the audit.

Word add-in

A lightweight task pane for quick checks inside Word. The current starter is read-only in behavior and avoids uploading manuscript text.

CLI and Python core

For reproducible workflows, research groups, CI tests, and future institutional integrations.

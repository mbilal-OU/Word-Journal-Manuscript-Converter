Three tools in one app

Choose only the workflow you need. Citation Navigator and Manuscript Audit do not require a journal profile.

Workflow 1

Journal Conversion

Check explicit journal requirements, apply supported formatting to a new copy, then verify that protected scientific content survived unchanged.

Workflow 2

Citation Navigator

Map in-text citations to references, save a clickable navigation report, create linked copies for plain numbered citations, or use live-safe Word navigation with citation-manager fields intact.

Workflow 3

Manuscript Audit

Inspect citations, fields, figures, tables, equations, comments, tracked changes, and other preservation-sensitive DOCX structures without converting anything.

Live citation fields stay live

For EndNote, Zotero, and Mendeley/CSL documents, Citation Navigator does not force hyperlinks into the field payload. The Word add-in provides click-to-jump navigation by moving the Word selection to the citation or bibliography paragraph.

Live-safe mode

Detect citation-manager fields, preserve them, and navigate without document mutation.

Clickable copy mode

When citations are plain numbered text, create a separate DOCX with internal bookmarks and links, then run the preservation gate.

Local navigation report

Export a clickable HTML citation map for review, debugging, or collaboration without selecting a journal.

Why only a few bundled journals?

Journal rules change. Built-in profiles are manually verified, source-dated, and limited to rules the engine can actually check. Custom JSON profiles already allow any journal while the verified library expands carefully.

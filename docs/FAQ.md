# FAQ

## Does Word Journal Manuscript Converter upload my manuscript?

Not for the current core workflow. Inspection, citation mapping, retargeting, and verification operate on local files.

## Will it break EndNote or Zotero citations?

The design goal is the opposite. Live citation-manager field signatures are treated as protected content. Automatic plain-text citation linking refuses to run when live manager fields are detected.

## Does it guarantee journal acceptance?

No. It checks only rules represented in the selected profile, and profiles can become outdated. Always verify current official author instructions.

## Can it convert any Word manuscript perfectly?

No. The project intentionally fails closed when it cannot establish that an automated transformation preserved protected content.

## Why use a desktop app instead of a web uploader?

A desktop-first workflow keeps unpublished research local and gives the core access to the complete DOCX package for stronger integrity checks.
